## 项目简介

**问问大师（wen6.0）是一款面向中文用户的沉浸式命理推演 Web 应用。** 它以东方命理与西方星象为双主线：输入出生日期、时间与地点后，你可以在同一份档案下阅读四柱八字、紫微斗数、本命星盘、运势时间线与关系合盘等推演报告。

与单纯的排盘工具不同，问问大师把**计算**与**阅读**拆成两层：

- **计算层**由纯前端引擎完成。排盘结果确定、可核对，出生信息默认只在浏览器本地参与运算。
- **阅读层**由引路人、场景演出、分层报告与「问问」对话组成。引路人现在有实际分工：按专长决定先看哪张卡、切换东方还是西方、打开哪款工具、带着什么问题追问。它们改变的是进入命盘的方式，而不是命盘本身——引路人不参与任何计算，AI 也不会改写已经算出的排盘数据。

应用基于原生 ES Modules 与 Vite 构建，无前端框架依赖；支持安装到主屏幕，并在资源缓存完成后提供部分离线推演能力。

### 为什么是「沉浸式」

| 层次 | 设计 | 作用 |
| --- | --- | --- |
| 场景 | 漏斗首屏 → 引路人邀请 → 命盘厅过场 | 把「查结果」变成一段有起点的探索 |
| 叙事 | 引路人语气、开场白与阅读线索 | 降低术语门槛，提供反思角度 |
| 路线 | 引路人按专长决定先读哪张卡、切换哪个体系、打开哪款工具与追问方向 | 让「选谁」真的改变接下来的阅读路径 |
| 交互 | 可旋转、缩放、点选的 Three.js 星象场景 | 让星盘从静态图片变成可观察的空间 |
| 阅读 | 新手解读速读、分区标签与可展开的专业数值 | 先给结论与行动建议，再按需核对依据 |
| 追问 | 「问问」结合当前命盘上下文对话 | 把一次性报告变成可持续的对话 |

首屏遵守「一屏一件事」：入口屏只留引路人、四步路线与一个进入按钮，预告屏只留一句开场白，四柱 / 评分 / 目录与完整说明都放到下滑后或「使用指南」里按需展开。完整的分层与文字预算见 [docs/content-flow.md](docs/content-flow.md)。

## 核心特性

### 东方命理推演

- **四柱八字**：年、月、日、时四柱干支，日主强弱、五行十神、用神与格局。
- **历法校正**：支持节气切换与真太阳时校正；农历数据覆盖 1900–2100 年，含闰月。
- **紫微斗数**：标准安星与十二宫信息，用于命盘速览与主题阅读。
- **时间与关系**：大运、流年、流日时间线，双人合盘与相处视角。
- **梅花易数**：以起卦方式提供的另一种东方解读框架。

### 西方星象推演

- **本命星盘**：行星落座、宫位、相位与关键角度。
- **星历计算**：按出生地时区及历史夏令时换算为绝对时刻，部分天体采用近似模型。
- **生命灵数**：基于出生日期的数字解读框架。
- **3D 星象场景**：拖动旋转、滚轮缩放、立绘收起与复位；不支持 WebGL 时自动回退为文字报告。

### 沉浸式引路人

首次进入时选择一位同行者。引路人除了叙事语气、开场白与场景演出，还会**真的带你走一条阅读路线**：预告页按他的专长挑三处已算出的线索、重排报告目录；报告首屏把同行场景、真实速读与「引路人指引」合并成一张主卡，四步路线就在卡内，可直接跳到对应卡片、切换东方 / 西方视图、打开对应工具，或把一个问题预填进「问问」。回到入口页可以重新选择。引路人**不参与排盘、评分或任何结论生成**。

首屏「进入命盘厅」按钮改用**一张精致的近黑漆面 / 古金云纹贴图**：六位共用 `public/art/cta-foil.webp`，不再用六套锯齿异形轮廓；切换右上角引路人时，贴图旋到该人物主题色，元素小徽章、主题渐变与文字一起变（月白月牙水波、玉宸玉圭、夕瑶四瓣桃花、焱绒元宝金锭、絮羽斜角塔罗牌、星罗星芒）。连续呼吸 / 闪烁已撤掉，只留极轻阴影与 hover / active / focus 反馈。元素、贴图与色相由 `src/ui/entry-personas.js` 的 `GUIDE_ELEMENTS` 单一定义，可在 `tools/preview-cta-shapes.html` 并排对照，`npm run test:guide-cta` 校验跨页一致性。

### 分层阅读

每份报告先给「新手解读」速读，用一段话说明当前状态、有利方向与下一步行动；下方按命盘、运势、关系分区，并用标签切换具体卡片。表格、结构表等专业数值默认收起，点「查看专业数值」即可展开核对。

同一份命盘只有一套计算结果，速读与专业数值来自同一组排盘数据，不存在两套结论。

### 主题工具集

工具中心收录 13 款工具：星座助手、塔罗、MBTI 人格、事业、择日、风水、今日日签、合盘、生肖、答案之书、摇签、起名与双色球 / 大乐透，覆盖日常反思与轻量娱乐场景。工具结果同样以文化体验与自我反思为目的。

### 问问对话

- 默认使用**内置模型**，无需填写 API Key。
- 可在「AI 设置」切换 DeepSeek / OpenRouter，并自行配置密钥。
- 结合当前命盘上下文流式追问；连接失败或额度不足时回退到本地知识库与离线回答。
- 报告中的本地计算与模板解读不依赖 AI。

### 分享、长报告与 PWA

支持生成分享海报与长报告，可将命盘摘要导出为图片；应用可安装到主屏幕，缓存完成后部分入口与推演功能可离线使用（AI 对话、天气与周边查询仍需联网）。

## 体验流程

1. **选择引路人**：在漏斗首屏挑选同行形象，决定接下来的叙事语气、演出与阅读路线。
2. **填写出生信息**：填写日期、时间与出生地；时间与地点会影响时柱、上升与宫位。
3. **阅读报告**：先看合并后的「同行 / 引路人指引」主卡，人物场景、真实速读与四步路线同屏；顶部切换东方 / 西方，底部切换命盘 / 运势 / 关系。
4. **继续追问**：在工具页体验主题工具，或打开「问问」结合当前命盘继续对话。
5. **保存与分享**：档案保存在本机浏览器，可导出、导入，或生成分享海报与长报告。

## 快速开始

### 在线体验

直接访问 **<https://kynessiscozy.github.io/wen6/funnel.html>**。首次进入会从漏斗页开始；也可以将应用安装到主屏幕后从 `funnel.html` 启动。

### 环境要求

- **Node.js 24+** 与 npm
- 运行浏览器测试时需要 Puppeteer 可用的 Chrome 及相应系统依赖

### 本地运行

```bash
git clone https://github.com/kynessiscozy/wen6.git
cd wen6
npm ci
npm run dev
```

打开 <http://localhost:5173/funnel.html>。开发服务器默认监听 `0.0.0.0:5173`，可通过 `PORT` 环境变量指定端口。

### 构建与预览

```bash
npm run build      # 生产构建，输出到 dist/
npm run preview    # 预览构建产物，默认 http://localhost:4173
npm run size       # 构建并统计产物大小
```

预览时访问 <http://localhost:4173/funnel.html>。项目使用相对基础路径（`base: './'`），可部署在静态站点的子路径下；PWA 与 Service Worker 需要 HTTPS 或 localhost 等安全上下文。

### 部署

推送到 `main` 或手动触发 GitHub Actions 后，[部署工作流](./.github/workflows/deploy.yml)会先执行构建与单元测试，通过后再将 `dist/` 发布到 GitHub Pages。其他静态托管环境也可直接发布 `dist/`。

## 新手入门与使用指南

> 第一次使用，建议按「开始 → 东方 → 西方 → 术语 → 问答」的顺序阅读。本节与「关于问问大师」「免责声明」三章和应用内弹窗同源，均由 `src/product-copy.js` 统一生成；改文案请先改数据源，再执行 `npm run sync:copy`。应用内可在菜单底部打开同样内容。

### 开始 · 一起看看，慢慢探索

选择一位引路人，从自己的问题出发，一步步走进命盘。

1. **选择引路人**：首次进入在漏斗首屏挑选同行形象。每位引路人都有自己的阅读路线：决定先看哪张卡、切换东方或西方视图、打开哪款工具，以及带着什么问题去「问问」。引路人不参与命盘计算；进入报告后，可在菜单点「返回入口页」重新选择。
2. **填写出生信息**：填写日期、时间与出生地后开始推演。时间和地点会影响时柱、上升与宫位，请尽量填写准确。结果出现后会停留，点击「查看报告」继续。
3. **阅读报告**：先看合并后的「同行 / 引路人指引」卡：人物场景、真实速读与四步路线都在同一张卡里；点路线可直接跳到对应卡片、打开对应工具或预填一个追问。顶部切换东方与西方，底部切换命盘、运势和关系；专业数值默认收起，点「查看专业数值」展开核对。
4. **继续探索**：预告页与报告里的路线会按引路人分别打开答案之书、事业大师、合盘助手、择日助手、塔罗大师或星座助手；「问问」也可结合当前命盘上下文继续追问。档案与偏好保存在本机浏览器。

### 东方 · 先看一览，再看依据

四柱和五行是一套传统的解读方式，不是对人生的定论。

1. **日主与四柱**：四柱由出生的年、月、日、时组成。日柱的天干称为日主，是阅读其余干支关系的起点。
2. **五行与用神**：一览显示日主、强弱、用神和格局。先读结论，再打开「五行结构」查看分布与依据；不同方法的判断可能不同。
3. **时间与关系**：在运势页查看大运、流年等时间线，在关系页阅读相处角度；结合现实处境判断，不必照单全收。

### 西方 · 从太阳、月亮和上升开始

出生时间和地点会影响结果。星盘按出生地时区及历史夏令时计算；夏令时切换时的重复或不存在的时间可能产生偏差。

1. **认识三个起点**：太阳、月亮和上升分别是占星解读中常用的三个视角。继续阅读可查看行星、宫位和相位。
2. **与星盘互动**：拖动场景可旋转视角，点击人物可收起立绘，再用「显示立绘」恢复。鼠标滚轮可缩放，复位按钮可返回初始视角。设备不支持 3D 时仍可阅读文字报告。
3. **查看星座参考**：星座运势文字和分值按日期与星座生成，不是实时天象或现实事件预测；六维图也是星座模板，并非科学测量。
4. **探索灵数**：关系页也提供基于出生日期的生命灵数体验。它是另一种解读框架，并非科学测量。

### 术语 · 遇到生词，先看这里

这些解释帮助你理解报告里的基本概念。

| 术语 | 体系 | 解释 |
| --- | --- | --- |
| 四柱 | 东方 | 出生年、月、日、时对应的四组干支。 |
| 日主 | 东方 | 日柱的天干，是四柱解读的参照。 |
| 用神 | 东方 | 传统命理中用于分析命局平衡的要素。 |
| 大运 / 流年 | 东方 | 分别指较长阶段与单年的时间线索。 |
| 上升 | 西方 | 出生时东方地平线升起的星座，受时间和地点影响。 |
| 相位 | 西方 | 星盘中天体之间的特定角度关系。 |
| 引路人 | 体验 | 陪你阅读报告的叙事角色：在一张同行 / 引路人卡里决定先看哪张卡、打开哪款工具与追问方向，不参与计算、不改结论。 |
| 速读与专业数值 | 阅读 | 报告先给结论与行动建议；表格、结构表等专业数值默认收起，可按需展开核对。 |

### 问答 · 使用前，了解这些

信息越准确，越方便你理解这份报告的计算前提。

- **不记得出生时间怎么办？** 请尽量核实。表单默认时间是 09:00；如果不确定，结果只是按所填时间计算，时柱和上升等内容可能不同。
- **引路人会影响命盘吗？** 不会。引路人决定的是阅读路线：先看哪张卡、用东方还是西方视图、打开哪款工具、预填哪个追问；排盘、评分与结论都不参与、不改写。在报告菜单点「返回入口页」可以重新选择。
- **报告里的专业数据在哪里看？** 每个分区顶部先给速读与行动建议，下方用标签切换具体卡片；表格、结构表等专业数值默认收起，点「查看专业数值」即可展开核对。
- **信息会保存或发送吗？** 出生信息在本地参与计算；档案和部分偏好保存在本机浏览器。问问对话默认使用内置模型，问题和相关上下文会发送给所选服务商；若自行配置第三方 API Key，密钥也会发送给该服务商。请避免输入敏感信息并留意其隐私政策。
- **天气和定位如何使用？** 打开菜单、穿搭或风水工具会尝试定位并联网查询。未授权时天气会尝试使用北京默认值；风水周边查询也会向外部服务发送坐标。

### 设计原则

1. **计算与叙事分离**：排盘由本地引擎一次性算出；引路人、AI 与视觉演出只作用于阅读层，不修改排盘结果。
2. **先结论，后依据**：默认先给可读的结论与解释，需要时再展开专业数据与推导细节。
3. **可解释、可核对**：报告中的术语可即时查询；算法与数据表有独立的交叉验证和审计脚本。
4. **克制与边界**：不做确定性预测，不使用恐吓式文案；重要决策始终交还给用户与现实中的专业人士。
