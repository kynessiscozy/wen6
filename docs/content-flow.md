# 首屏内容流（2026-11-12 梳理）

## 为什么要重排

引路人阅读路线功能上线后，信息被「补」到了每一屏，而不是「排」进流程：

- **漏斗首屏**底部一次堆了 7 行小字：身份（月白 · 全能推演）＋作用说明（引路人决定先看哪张卡 / 打开哪款工具，不参与排盘）＋路线标题＋四步 chips＋「预告页与报告里可直接点开这四步」＋两行隐私 / 免责。全部压在视频下方 30% 区域，且套了一层带边框的卡片，视觉上就是一坨。
- **预告页首屏**的云端开场白允许 80–120 字，本地兜底又是「开场＋日主性格 30 字＋重复的 lead＋『下面三处』引导」四个分句。
- **下滑后**四柱、三句钩子、四步路线、完整报告目录四张卡片连成一整屏文字墙，其中「完整目录」与「四步路线」讲的是同一批卡片。
- 同一句「引路人决定先看哪张卡、不参与计算」在首屏、使用指南、报告指引里出现三次。

结果就是：用户还没做任何选择，先要读完一整段说明。

## 三条原则

1. **一屏一件事**：入口屏只选人 + 进场，预告屏只认人 + 往下看，报告屏才读数据。
2. **一句只出现一次**：作用说明、阅读路线、隐私与免责各有一个归属，不跨屏复述。
3. **解释按需展开**：想弄清「引路人到底做什么」的人有一个明确入口（首屏路线条 → 使用指南）；不想看的人不被迫读完。

## 流程表

| 屏 | 唯一任务 | 首屏保留 | 移走 / 按需展开 |
| --- | --- | --- | --- |
| 漏斗首屏 `#s-entry` | 选引路人、进场 | ① 身份一行「月白 · 全能推演」；② 路线一行「这位引路人会带你走 / 四柱与日主 → …」；③ 主按钮「进入命盘厅」；④ 隐私一行 | 「引路人决定先看哪张卡…」→ 使用指南「开始 / 问答」；「预告页与报告里可直接点开这四步」→ 预告页路线卡；免责声明 → 免责面板；六位专长 → 右上角切换菜单 |
| 沉浸过场 / 问卷 / 加载 | 收信息、做仪式 | 每人分版的一句台词与题目 | 不动，原本就不堆字 |
| 预告页首屏 `.ft-hero` | 认人、引导下滑 | 人物标识 + 姓名行 + **一句 40–60 字开场白** + 下滑提示 | 30 字日主性格长句、重复的 `lead`、「下面三处…」全部删除；四柱 / 评分 / 目录留到下滑后 |
| 预告页内容层 `.ft-sheet` | 给真数据、给可点路线 | 四柱卡、三处钩子、四步可点路线 | 「完整报告目录」改为 `<details>` 默认收起；路线说明压成一句；信任行压成一句 |
| 报告「同行 / 引路人主卡」 | 认人 + 读数据 + 执行路线 | 身份一行、真实速读 / 星盘、引路人视角、四步路线 | 两张旧卡合并为一张；边界说明只在卡内与使用指南出现 |

## 首屏文字预算

| 位置 | 改动前 | 改动后 |
| --- | --- | --- |
| 漏斗首屏底部 | 7 行 + 一个带边框卡片 | 3 行文字（身份 / 路线 / 隐私）+ 1 个按钮 |
| 预告页开场白（云端） | 80–120 字 | 40–60 字，缓存键 `wen_teaser_copy_v4` |
| 预告页开场白（本地兜底） | 4 个分句、约 70–90 字 | `route.opening` + 一句日主，约 25 字 |
| 预告页下滑内容 | 4 张全展开卡片 | 3 张卡片 + 1 个默认收起的目录 |

## 不变的东西

- 引路人的**功能**没变：`src/ui/guide-route.js` 仍是唯一数据源，六条路线、四步动作、真实卡片 / 工具 / 追问全部保留；报告里只是把同行卡与引路人卡合并成一张主卡并重排布局。
- 计算边界没变：不写输入、不重算、不碰评分 / 结论 / AI 改写。
- 本轮版本没动：产品 `wen6.0` / npm `6.0.0`，视频素材 `v76` / `?v=76`，当时应用缓存 `wenda-cache-v78`。HTML 走 network-first，静态资源带 hash，因此本次不需要升 SW 缓存版本；后续新增首屏贴图并纳入预缓存后，缓存已同步升到 `wenda-cache-v79`，产品与视频版本仍未动。

- `public/funnel.html`：首屏 CSS / 结构、`#btnGuideRoute` → `fmOpenPanel('guide')`、Esc 关闭面板并归还焦点。主按钮后续先按引路人元素做异形轮廓，又按「首屏的按钮很丑 / 精致的贴图」反馈推翻异形，改用共用箔纹贴图 + 元素徽章（见 `docs/v6.1-guides.md` 的「首屏按钮精致贴图」），始终不增加文案。
- `src/ui/character-report.js` / `src/character-report.css`：2026-11-12 再把报告里的同行卡与引路人卡合并成一张主卡并重排布局；流程表「报告」一行随之更新。详见 `docs/v6.1-guides.md` 的「同行 / 引路人卡合并重排」。
- `src/ui/funnel-teaser.js`：兜底开场白、`<details>` 目录、`ft-open` 行距、说明文案。
- `src/ui/teaser-copy.js`：开场白字数、长度守卫、缓存键。
- `src/ui/entry-personas.js`：删除已无人读取的 `lead / circle / hooksTitle`，开场白与钩子标题只由 `guide-route.js` 提供。
- `tools/test-guide-route.mjs` / `tools/test-entry-flow.mjs`：新增断言锁定「首屏不重复解释、路线条可点、目录默认收起、开场白 40–60 字、单一文案源」。
